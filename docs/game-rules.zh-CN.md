# Modoban 游戏规则

本文记录设计讨论中已确认的现行规则，作为原型实现与关卡设计的依据。第 11 节汇总当前原型的配置约束。

## 1. 游戏目标与原型范围

Modoban 是俯视网格、回合制的推箱机关解谜游戏。玩家操纵角色，通过推箱、运输、制动和伸缩机关，最终到达关卡出口。

- 通关条件是角色在整条自动连锁结算结束后位于出口。
- 箱子和石块用于搬运、压板、卡住周期轴和传递推力，当前没有要求所有物体到达指定目标的通关条件。
- 玩家可以停下来思考，机关只在有效玩家行动及其引发的自动连锁中发生动作。
- 玩家可以无限撤销，恢复完整回合状态。
- 当前关卡仍在单一活动层上按网格结算。三维呈现不改变移动与机关的逻辑规则。

载入时保留关卡配置的物体位置、门的初始伸缩状态与周期拍位，计算控制信号，自动运输和门动作从首次有效行动开始结算。角色初始就在出口时直接通关。

数论思想主要表现为周期与余数、行动拍数与棋盘位置的奇偶关系，以及局部停止周期轴后形成的相位差。关卡通过空间关系呈现这些性质。

## 2. 地图与占用

### 2.1 分层

| 层 | 内容 | 占用含义 |
| --- | --- | --- |
| 地面机关层 | 地面、压力板、传送带、卡槽、出口等 | 提供通行基础、触发条件或位置标记 |
| 固定机关 | 周期轴底座 | 占据地图内一格，固定阻挡实体，不可推动、输送或破坏 |
| 实体占用层 | 玩家、箱子、石块、伸出的门体 | 同一格最多容纳一个实体 |
| 安装边 | 收起的伸缩门及其安装位置 | 门收起时不占据相邻格子，安装件本身允许跨边通行 |

每格最多放置一个地面机关，压力板、传送带、卡槽等地面机关彼此不能叠放。

地面机关与实体可以位于同一格。例如箱子或石块可以站在传送带或压力板上，门体也可以覆盖地面机关。边框安装的门与伸出的门体分别按安装边和实体占用规则处理。

墙、周期轴底座、地图边界和已伸出的门体提供固定阻挡。周期轴底座与门永远不会被破坏，已伸出的门体作为固定障碍处理。

### 2.2 哪些物体触发机关

- 玩家、箱子和石块可以被传送带运输，也可以触发压力板。
- 卡槽接收箱子或石块，用占用物体卡住对应周期轴。
- 门体不会触发所在格子的地面机关，也不会被传送带运输。
- 门把箱子推出压力板后，压力板松开。伸入该格的门体不会代替箱子继续压住压力板。

### 2.3 可移动物体与硬度

| 物体 | 功能 | 相对硬度 | 可破坏 |
| --- | --- | --- | --- |
| 石块 | 可以推动、输送、压板和卡住周期轴 | 最高 | 是 |
| 箱子 | 可以推动、输送、压板和卡住周期轴 | 居中 | 是 |
| 玩家 | 主动行动，也可以被门推动、被传送带运输和触发压力板 | 最低 | 是，被破坏即失败 |

只有可推动的物体能被破坏，当前包括玩家、箱子和石块。石块与箱子的功能相同，区别在于硬度。硬度关系为 `石块 > 箱子 > 玩家`。

硬度用于门受阻时的破坏选择，不限制玩家推动石块。门、墙和地面机关均不参与可破坏物体的硬度比较。

## 3. 玩家行动与回合

### 3.1 主动行动

- 玩家每次向上、下、左、右主动移动一格。
- 前方是箱子或石块时，可以把一个物体向同方向推一格，前提是该物体有合法落点。
- 玩家只能主动推动一个箱子或石块，不能拉动。门的推力规则见第 7 节。
- 没有全局原地等待操作。玩家可以通过路线与机关形成局部等待。
- 撞墙、推不动物体或其他无法完成的主动移动属于无效操作。
- 无效操作不改变局面，不清空传送带标记，不推进周期，也不启动自动连锁。

### 3.2 一个有效回合

1. 确认主动行动可以执行，开启新回合，清空所有物体的传送带标记。
2. 完成玩家的主动移动或推箱。
3. 根据主动行动完成后的卡槽占用状态，将未被卡住的周期轴推进一拍。
4. 结算自动连锁，直到局面稳定或发生失败。
5. 稳定后检查出口，再允许执行下一次玩家行动。动画期间可以提前接收输入，按第 12 节处理。

每个有效玩家回合只推进一次周期轴。传送带运输、门推挤、压力板变化和其他自动反应都不额外增加拍数。

玩家能否通过门，依据主动行动执行时门体的实际占用状态判断。

### 3.3 撤销

一次撤销恢复到本次有效行动开始前的完整局面，包括物体位置与存活状态、门状态、周期拍位、传送带标记，以及影响后续结算的状态。

破坏物体、角色失败和机械死循环都应当可以通过撤销恢复。自动连锁的内部小步属于同一个玩家回合。

## 4. 统一的门与控制条件

### 4.1 门的安装与伸缩

所有门采用同一种有方向的伸缩机构，安装在格子边框上，沿指定方向伸入相邻一格。

例如格子 1 和 2 左右相邻，门安装在格子 1 的右边框、朝左伸出。

| 状态 | 格子 1 | 格子 2 |
| --- | --- | --- |
| 收起 | 可正常使用 | 可正常使用 |
| 伸出 | 被门体占据 | 可正常使用 |

门收起时缩在边框内，安装边可以正常通行。格子 2 无需充当永久占地的底座。

- 伸出时，门尝试占据目标格，并沿伸出方向推挤其中的物体。
- 门保持伸出时持续占据该格，保持状态不会再次产生推力。
- 收起时只回收门体，相邻物体保持原位置。

### 4.2 控制来源

周期控制和压力控制驱动同一种伸缩门，门的占用、推挤和破坏规则相同。

- 每扇门配置一个初始状态，可以是伸出，也可以是收起。初始状态同时作为控制计算的基准。
- 周期控制根据对应周期轴的当前拍位输出真或假。
- 压力板被玩家、箱子或石块占据时输出真，空置时输出假。
- 一扇门可以接收多个输入。只有所有输入均为真时，门的目标状态才取反初始状态；存在假输入时，目标状态等于初始状态。
- 没有控制输入的门保持初始状态对应的目标状态。
- 多扇门可以共用一个周期轴，形成共同停止、共同恢复的机关组。
- 控制条件只给出目标状态。门能否实际伸出，还要根据当前空间、物体与破坏规则判断。

将伸出记为真、收起记为假，有输入时的计算公式为 `目标状态 = 初始状态 XOR AND(所有输入)`。

| 初始状态 | 所有输入均为真 | 目标状态 |
| --- | --- | --- |
| 收起 | 否 | 收起 |
| 收起 | 是 | 伸出 |
| 伸出 | 否 | 伸出 |
| 伸出 | 是 | 收起 |

取反以初始状态为基准。持续为真的输入维持同一个目标状态；重新检查控制条件不会反复翻转门。输入从全真变为存在假时，目标状态恢复初始状态。

## 5. 周期轴、卡槽与压力板

### 5.1 周期轴

周期轴具有循环拍位，关卡需要明确其周期、初始拍位，以及各拍位向门输出的布尔状态。

- 每根周期轴都有地图坐标，以占一格的固定机座存在。玩家、箱子、石块和门体不能进入其格子；底座不能与墙、出口、地面机关、其他底座或任何门的安装格重叠。
- 底座可以放在角落或不可到达的地图孤岛上。距离和玩家是否能接近，不影响周期推进。
- 每一拍的真/假输出由关卡独立配置，允许任意连续或不连续的模式；玩家不直接点击拨拍、修改配置或搬动底座。
- 底座上的周期圆盘显示真/假输出和当前拍位；真信号与压力板被压住一样作为控制输入，门再根据初始状态和全部输入决定伸缩。
- 周期轴、它控制的门及关联刹车槽同色；压力板沿用相同的控制组配色。经同一扇门连接的控制源归为同一颜色组，互不相连的组使用不同颜色。颜色不随输出或制动状态切换。

四拍、六拍是典型示例。页面应让玩家直接看见周期位置，例如用少量刻度标记当前拍位。

周期轴每个有效回合最多推进一拍。门伸出受阻不会停止周期轴。

### 5.2 卡槽

- 每个卡槽只对应一个周期轴，以明确的组号或连接关系表达。
- 卡槽是独立的地面格，必须与对应底座上下左右相邻，不能斜接或与底座重叠。
- 同一周期轴关联多个卡槽时，任意卡槽被箱子或石块占据都会停轴，全部释放后恢复推进。
- 箱子或石块进入卡槽后卡住对应轴，保留当前拍位和周期输出。
- 门仍根据全部输入计算控制目标，实际状态受空间阻挡影响。
- 停轴只冻结该轴的拍位与输出；其他轴、压力板和门继续正常结算。
- 箱子或石块离开卡槽后，卡槽释放对应轴的停止条件，轴恢复推进时从停止的拍位继续。
- 主动推箱进入或离开卡槽，会影响本回合第 3 步的周期推进。
- 自动连锁中进入或离开卡槽，会立即更新锁定状态。本回合的周期推进已经完成，后续有效回合再按新状态推进。

卡槽与压力板都可以使用箱子或石块。原型通过槽位样式表达物体卡住传动机构的关系。

### 5.3 压力板

- 玩家、箱子或石块占据压力板时，压力板处于被压住状态，输出真。
- 占用物体离开或被破坏后，压力板松开，输出假。
- 压力板状态改变后，在同一玩家回合的自动连锁中更新对应门。
- 持续压住压力板会维持控制状态，持续占用本身不会重复产生新动作。

## 6. 传送带与逻辑 ID 标记

### 6.1 输送能力

- 玩家、箱子和石块都能进入传送带。
- 一次成功输送沿当前所在传送带格子的箭头移动一格。
- 输送采用当前实际布局。目标格可进入时才能移动。
- 传送带运输受阻时停住，输送本身不推挤静止物体。
- 如果前方物体之后移开，尚有输送资格的物体可以在同一回合重新尝试。
- 输送不会额外推进周期。

### 6.2 逻辑 ID

一条逻辑传送带的所有格子共用同一个 ID。方向拐弯可以仍属于同一条带。关卡需要清楚表达不同逻辑带之间的分界。

每个可输送物体具有独立的传送带标记。

| 事件 | 标记与输送资格 |
| --- | --- |
| A 带成功输送物体一格，落点仍在 A 带 | 记录 A，本回合留在 A 内期间不再被 A 输送 |
| 在 A 带内部被其他机关移动，仍未离开 A | 保留 A 标记 |
| 物体离开 A，进入普通地面 | 清除 A 标记 |
| 物体从 A 进入 B | 清除 A 标记，可以被 B 输送 |
| B 输送后落点仍在 B | 记录 B |
| 物体离开后在同回合重新进入 A | 可以再次被 A 输送 |
| 输送受阻，物体未移动 | 不产生新的输送标记 |
| 下一次有效玩家行动开始 | 清空所有物体的输送标记 |

标记的写入与离开检查属于同一次移动的完整处理。例如 A 把物体送入 B，A 标记随离开 A 清除，之后按 B 的资格继续结算。

标记只在有效回合开始时统一清空。自动连锁的小轮、无效操作和等待输入都不会清空标记。

### 6.3 进入与回合开始的输送

- 玩家主动进入传送带或把箱子推入传送带，都会在本回合自动连锁中尝试输送。
- 门把物体推上传送带，立即进入同回合的输送结算。
- 原本就在带上的物体，在新有效回合清空标记后，也重新获得输送资格。
- 同回合进入不同逻辑带，可以分别被各条带输送。
- 同回合多次离开、重新进入同一逻辑带，也可以被该带输送多次。
- 整条连锁可能产生多次自动位移，是否继续由当前位置、标记、阻挡和其他机关动作共同决定。

### 6.4 玩家在传送带上行动

以向右的传送带为例，假设本次输送有空间且物体有输送资格。

| 玩家主动行动 | 后续反应 |
| --- | --- |
| 向右移动后仍在该带 | 自动再向右一格，总位移两格、周期推进一拍 |
| 向左移动后仍在该带 | 自动向右一格，可回到原位置、周期推进一拍 |
| 移动到普通地面 | 留在该地面 |
| 移动到另一条逻辑带 | 按落点传送带的方向与 ID 结算 |
| 主动移动失败 | 整个回合不发生 |

被挡住的自动输送不会撤回已经完成的主动移动。局部逆行产生的原地踏步是合法的节奏调整手段。

## 7. 门的整排推挤与破坏

门的推挤与破坏规则不因方向而改变：沿伸出方向检查整排物体及其前方空间，有空位则推进，受固定障碍阻挡时按硬度选择破坏对象。向下门遵循同一规则；当前关卡的活动层下方是连续地面，地面提供固定阻挡，因此向下伸门会压毁本格的占位物。将来若下方存在可用空间，应按相同规则向下推动，而不是无条件破坏。

向上门留待高度机制引入后实现：抬起的物体只允许向同高度落脚点移动。

### 7.1 整排推挤

门伸出时，沿伸出方向检查连续排列的可移动物体。玩家、箱子和石块都参与这条物体链。

- 末端有合法空位时，整排物体各向前移动一格，门占据腾出的目标格。
- 遇到墙、边界、已伸出的门体或其他固定阻挡时，按破坏规则继续判断。
- 一次伸出包含必要的破坏、推挤和门体落位，作为完整动作结算。
- 动作完成后，再让新的占用变化触发后续机关。

### 7.2 受阻后的破坏

受阻时，在本次推挤链中的可破坏物体里，先选择硬度最低的物体；只有硬度相同时，再选择沿伸出方向距离该门最近的物体。

- 破坏优先级为玩家、箱子、石块。
- 即使玩家距离门更远，只要链中存在玩家，也会优先于箱子或石块被破坏。
- 如果链中只有石块，石块也可以被破坏。
- 门永远不会被破坏，墙、地面机关等固定结构也不属于破坏候选。

破坏产生空位后，推动该空位之前的物体并完成伸出。空位之后的物体保持原位置。

例如以下一排受墙阻挡。

```text
门 → 石块 箱子 石块 墙
```

门破坏硬度最低的箱子，前面的石块移入空位，门伸入原来第一个石块的位置；靠墙的石块保持原位。

如果排列是 `门 → 箱子 玩家 墙`，则先破坏玩家，随即进入失败状态。

如果无法通过推挤和允许的破坏产生合法落位，门保持原状态。之后条件仍要求伸出、且局面变化产生新机会时，可以重新尝试。

破坏造成的压力板松开、卡槽释放等变化参与同一回合的自动连锁。

## 8. 即时连锁与执行顺序

### 8.1 自动结算小轮

周期推进后，反复执行以下自动结算小轮。

1. 根据当前占用刷新压力板、卡槽和控制条件。
2. 按内存中的存储顺序逐个尝试传送带输送，每个动作读取执行时的最新局面。
3. 根据输送结果刷新控制条件。
4. 按内存中的存储顺序逐个检查门的目标状态，并完成可执行的伸缩动作。
5. 根据变化继续结算，直到稳定或失败。

每个完整动作造成的占用、标记和控制条件变化，应供后续动作读取。已经排队的检查在执行时仍需依据最新状态判断。

例如门把箱子推上传送带，该物体在接下来的输送小步移动；推上压力板，对应门在后续门检查中响应。整个过程发生在同一玩家回合，展示时连续播放。提前输入可以加快动画收尾，下一次行动以本回合结算后的局面为起点。

未改变局面的检查不会单独产生新一轮连锁。传送带被堵住、门暂时伸不出，都可以构成稳定局面的一部分。

### 8.2 冲突采用先结算者为准

- 两条带向同一格送物体，先执行的成功占据，后执行的依据最新占用判断阻挡。
- 两扇门伸入同一格，先执行的门体占据该格，后执行的根据当前阻挡结算。
- 同一结算阶段内按机关在内存集合中的顺序执行，无需额外按 ID、位置等排序。
- 内存顺序属于会影响结果的逻辑状态。加载、撤销和重放应保留该顺序，动画快慢不改变执行顺序。
- 存储顺序用于保证执行确定性。关卡设计不应依赖隐藏优先级作为解题关键。

### 8.3 交叉推挤

假设 A 从下向上把物体推入交汇格，B 从右向左伸入同一交汇格。

- A 先执行时，物体先向上；B 随后尝试向左推动物体。左侧受阻时，B 再依据破坏规则判断。
- B 先执行时，交汇格已被门体占据；A 的向上推挤受阻，再依据破坏规则判断。
- 交叉方向本身不会直接判定破坏。

如果关卡需要明确表现“先上再左”，应建立可见的因果顺序。例如 A 把箱子推上压力板，压力板再驱动 B。

## 9. 机械死循环、失败与通关

### 9.1 稳定与循环

连锁中仍然允许出现真实闭环。例如箱子离开 A 带后被门推回 A，清除标记后又被 A 输送，最终恢复此前完整局面。

在自动结算的固定阶段记录完整逻辑状态。完整状态需要覆盖物体位置、存活与类型，门的初始及实际状态，周期拍位，控制状态，传送带标记，机关存储顺序，以及影响执行结果的阶段或待处理反应。

- 整轮没有实际动作或状态变化时，连锁稳定结束。
- 连锁中发生动作后，同一结算阶段再次出现此前的完整状态时，判定机械死循环，停止结算并进入故障状态。
- 稳定检查应区分“整轮没有动作”和“执行了一圈动作后恢复原状”，后者属于循环。
- 标记不同的两个局面属于不同状态，即使物体位置相同。
- 画面动画进度不参与逻辑循环判断。

对于有限地图、有限状态且结算确定的原型，自动连锁最终会稳定或重复完整状态。实现时需要保证任务调度自身不会无变化地重复排队。

### 9.2 失败与出口

- 玩家被门按硬度规则选中破坏时，立即进入失败状态。
- 机械死循环属于可撤销的故障状态。
- 自动连锁中途经过出口还需继续结算，稳定后角色仍位于出口才通关。
- 被破坏的箱子或石块释放原位置，并引起对应地面机关状态变化。

## 10. 规则核对案例

以下案例用于后续实现核对。

| 场景 | 预期结果 |
| --- | --- |
| 玩家撞墙 | 位置、周期、输送标记均保持原状 |
| 玩家把箱子推上 A 带 | 箱子在本回合尝试自动输送一格 |
| 箱子被 A 输送到另一格 A | 记录 A，本回合留在 A 内期间停止再次输送 |
| 箱子被门在 A 内推动一格 | 原有 A 标记继续有效 |
| 箱子从 A 被送到 B | 清除 A 标记，按 B 的规则继续输送 |
| 箱子同回合离开 A 后重新进入 A | 重新获得 A 的输送资格 |
| 箱子输送受阻，稍后障碍被门移开 | 若尚有资格，同回合可重试 |
| 新有效回合开始，箱子仍在 A 上 | 清空旧标记，重新获得输送资格 |
| 门把箱子推上压力板 | 同回合更新对应门的控制条件 |
| 门占据压力板格 | 门体不会触发压力板 |
| 门伸出后一直维持伸出 | 保持占格，不重复推挤 |
| 门收起 | 物体保持当前位置 |
| 门受阻，链内同时有玩家、箱子、石块 | 优先破坏玩家，立即失败 |
| 门受阻，链内有多个箱子和石块 | 先选择箱子，同硬度取离门最近的 |
| 门受阻，链内只有石块 | 破坏离门最近的石块，利用空位继续推挤 |
| 门受阻，无法产生合法空位 | 门保持原状态，周期照常推进 |
| 初始收起的门，全部输入为真 | 目标状态为伸出 |
| 初始伸出的门，全部输入为真 | 目标状态为收起 |
| 任意初始状态的门，至少一个输入为假 | 目标状态等于初始状态 |
| 门的全部输入持续为真 | 维持取反初始状态后的目标，不重复翻转 |
| 石块进入传送带、压力板或卡槽 | 分别按与箱子相同的功能结算 |
| 同一格配置两个地面机关 | 关卡配置不合法 |
| 两个机关争抢同一格 | 后执行者读取前执行者造成的新局面 |
| 连锁中完整状态再次出现 | 判定机械死循环，可撤销 |
| 角色中途到出口，随后被带走 | 稳定后位置决定通关结果 |
| 撤销包含破坏或故障的回合 | 恢复行动前完整状态 |
| 箱子经传送带到压力板，再被门转向推出 | 按因果连续播放两段位移，压板变化在抵达时交接，门与被推物体同步运动 |
| 多个机关动作没有空间或控制依赖 | 动画可以并行，逻辑结果保持内存顺序结算的结果 |
| 动画期间收到下一次方向输入 | 最多暂存一次输入，加快当前动画收尾后，从结算后的局面执行 |
| 动画期间撤销 | 取消当前回合的剩余动画与暂存移动，恢复撤销后的完整局面 |

## 11. 当前原型的配置约束

关卡配置应满足以下约束。

1. **实体种类**。当前可推动、可破坏的物体为玩家、箱子和石块，门体作为固定阻挡且不可破坏。
2. **门配置**。每扇门明确安装边、伸出方向、初始状态和输入列表。多个输入按全部为真判定，目标状态相对初始状态取反。
3. **卡槽绑定**。每个卡槽只绑定一个周期轴。
4. **格子占用**。每格最多一个地面机关、一个实体。边框安装与门体覆盖按分层规则处理。
5. **传送带配置**。每格明确方向和逻辑 ID，同一逻辑带的格子共用 ID。
6. **结算顺序**。采用内存集合顺序，重放与撤销保留顺序。

当前规则范围为二维网格原型。

## 12. 动画、输入与关卡连锁长度

### 12.1 逻辑结果与动画展示

逻辑结算生成本回合的最终状态与动作记录，包括位移、机关状态变化、门伸缩、破坏和故障。动画根据动作记录展示过程，动画播放进度不触发新的逻辑动作，也不推进周期。

后续玩家行动始终基于已结算的正确局面。动画尚在展示中间过程时，可以提前接收输入，具体规则见 12.4。

### 12.2 按因果连续播放

- 存在物体、空间或控制关系依赖的动作保留逻辑先后。物体先抵达压力板，压力板的控制结果再驱动门。
- 同一次门动作中，门体与被推动的一排物体同步运动，破坏效果也在该动作中呈现。
- 没有空间、物体或控制关系依赖的动作可以并行展示。视觉上的并行保持已经确定的逻辑结果。
- 前后动作直接交接，减少额外停顿。连续同向位移可以合并为连贯运动，转向采用短促过渡。
- 失败或机械死循环展示到相应触发位置，便于玩家理解并撤销。

例如箱子被传送到压力板后，门再把它向另一方向推出，可以采用以下节奏作为原型调参参考。

| 时间示例 | 展示内容 |
| --- | --- |
| 0～100ms | 箱子被传送到压力板 |
| 约 100ms | 箱子抵达，压力板呈现被压下的状态，立即交接门动作 |
| 100～200ms | 门伸出，箱子随门一起向另一方向移动 |

这些时间用于表达连续交接的手感，实际时长根据原型试玩调整。

### 12.3 短连锁优先

- 动画优先保证普通移动及一到两次短连锁的流畅度、响应速度和因果可读性。
- 普通回合可以先以约 150～300ms 作为调参参考，避免每一格都重复完整的启动、减速和停顿。
- 长连锁允许适当压缩展示细节，也允许延长播放时间，具体取舍服从短连锁的手感目标。
- 可以先合并独立动作和连续运动，再根据需要调整长连锁的播放速度。
- 动作记录支持慢速回放或单步查看，用于观察复杂因果过程。

### 12.4 动画期间的操作

- 动画期间可以接收下一次方向输入，最多暂存一个待处理输入。再次输入会替换这个待处理方向，避免积累长操作队列。
- 收到提前输入后，加快当前回合动画收尾，呈现已经结算的最终局面，再执行暂存输入。
- 是否能够移动，以执行暂存输入时的最终局面判断。无效操作继续遵守第 3 节规则。
- 已结算为失败、故障或通关时，清除暂存移动输入，呈现对应结果；失败和故障保留撤销操作。
- 撤销可以取消当前回合的剩余动画和暂存移动，恢复完整逻辑状态并使画面与之对齐。

### 12.5 关卡设计原则

关卡中的连锁以一到两次机关相互触发的短连锁为主，优先让玩家清楚看见自己的操作如何改变局面。

长连锁可以存在，其细节可读性与演出时长允许按场景取舍。原型的主要手感验证围绕普通移动、推箱、单次输送，以及输送后触发门等短连锁展开。
