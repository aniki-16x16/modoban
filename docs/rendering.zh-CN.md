# 三维呈现

游戏棋盘使用浏览器原生 WebGPU 与 WGSL，不引入渲染库。关卡选择继续使用二维 SVG 缩略图。目标平台为桌面浏览器；不支持 WebGPU 或设备丢失时显示明确提示，不切换到其他渲染后端。

HTML 直接提供启动 loading，动画样式内联，不依赖应用脚本或样式下载。给浏览器首次绘制机会后再加载 React 应用；页面和关卡的 GPU 初始化也延后启动，让等待状态先显示。关卡准备期间沿用同一组方块动画，首帧提交后移除；初始化失败时改为错误提示，系统要求减少动态效果时保留静态图案。

- 世界坐标以 X、Y 对应关卡网格，Z 表示高度。当前关卡仍在单一活动层结算。
- 玩家保留橙色和笑脸，呈现为较高的圆柱。地面机关及出口保持低矮；周期轴有独立底座和可读的拍位刻度。
- 门的安装花纹位于占据格反方向的网格面上，实体边框向门格内凸出少量厚度，收起时仍能辨认安装位置。门体沿面法线伸缩，完全伸出时为半透明发光立方体，控制组颜色保持一致。透明表面按相机深度排序，使用深度测试；不透明物体先绘制并写入深度。
- 镜头只绕 X 轴倾斜俯视，不绕 Z 轴旋转，不提供旋转、拖动或缩放。`ChapterLevel.camera` 可设置 `elevation`、`fov`（单位为度）。未设置时使用统一默认值；根据场景全部包围盒顶点及画布宽高比计算距离，保留边缘余量。
- `PlaybackFrame` 是渲染的唯一状态来源，位移、门伸缩、机关响应、破坏、撤销与重置遵循引擎时间线。空闲时不重复提交画面；状态变化或画布尺寸变化时重绘。
- 几何体由 `src/render/scene.ts` 生成；相机计算在 `math.ts`；WebGPU 管线与资源生命周期在 `renderer.ts`。模型顶点常驻 GPU，角色位移、拉伸与门伸缩只更新变换矩阵；门的边缘及角色五官单独变换，保持原有粗细。机关的离散外观按状态缓存，首次出现时追加模型，撤销与重置复用已有模型。
- `batch.ts` 维护模型顶点、变换及绘制索引。透明三角形统一按世界深度排序；未变化物体保留已有深度和顺序，变化部分排序后与其合并，仅上传顺序实际改变的索引区间。重复绘制同一画面不上传数据、不提交命令；缩放画布只更新相机与渲染附件。
- 设备、管线、绑定组和缓冲区跨关卡复用；切关时替换当前场景的数据，避免积累已访问关卡的 GPU 模型。退出关卡时解绑画布和错误回调，保留共享资源以便再次进入；设备丢失后重新创建。压力板轮廓使用连续圆环；画布至少以 1.5 倍像素密度渲染，并使用四倍多重采样。

WebGPU API 与混合、深度配置参照 [W3C WebGPU 规范](https://www.w3.org/TR/webgpu/)。
