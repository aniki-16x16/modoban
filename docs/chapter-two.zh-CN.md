# 第二章：步数与节拍

第二章引入周期轴与周期门，把有效行动的拍数和空间中的运输、站位与回程结合起来。01「合拍」学习周期运输，02「候场」保护暂存箱，03「接驳」将第一章的反向门与同一周期组合，04「放行」结合压力与拍位共同许可，05「共台」在两个不同周期下安排共用转运口的进料、暂存与回收。沿用已经教过的箱子、压力板、多输入和门推挤，不引入传送带或停轴。

## 01 合拍：先装载，再回收，最后交接

- 地图 15 × 11，两箱、三压板、四扇压力门、两扇周期门和一个周期轴。左房间安排箱子分工与装载，右侧竖道负责运输，下方通道承担回程，右房间提供暂存和交接空间。周期轴放在右上角不可到达的孤岛上，与两扇周期门同色。下文用 A、B、C 分别指紫色装载压板、青色回程压板和玫红色终点压板。
- 入口先安全展示四拍周期：前两拍关闭、后两拍收起，有效行动才推进一拍。入口门下方留有安全落点，即使恰逢关门，也只会把角色推入房间。随后在主区域把同样的开闭规律用于箱子转运。
- 第一层矛盾：A 既是打开装载通道的开关，又是向右推送货箱必需的站位。若先让一箱长期压住 A，另一箱就无法进入上方通道。需要先把货箱送到门前暂存，再安排控制箱压住 A；也可以在发现占位冲突后移开箱子、重新分工。左房间保留绕行位置，两只箱子都可以承担货物或控制任务。
- 装载点上方和右侧都是墙，角色没有向下推箱的站位。趁周期门收起时把货箱送进门格，再利用门伸出将它推入竖道；之后还要等门收起，进入它让出的站位，把货箱继续送往 B。节拍决定装载与卸载的窗口，门的推力负责完成普通推箱无法完成的转弯。
- 第二层矛盾：货箱暂压 B 打开下方回程，但从 B 推回终点 C 时，回程门会关闭，C 上的箱子又会堵住上方竖道。必须提前回收 A 的控制箱，从下路带进右房间，再让它接替 B。B 还控制出口前的一扇门，货箱首次经过 C 时不能直接离场。
- 第三层矛盾：带来的控制箱可能占住 B 下方的推箱站位，也可能被过早推入无法回收的角落。右房间的侧边和上方侧位都能暂存，需先让出站位，再在货箱离开 B 后回填。若控制箱仍留在 A 就提前完成 C，角色会被困在右侧，需要撤销。

## 02 候场：先保护暂存箱，再放行运输

- 地图 17 × 10，两箱、四块压板、六扇压力门、一扇周期门和一个周期轴。上方横道承载第一箱，中央桥是第二箱的运输路，下方通道承担回程，左右房间分别提供暂存和终点准备空间。A 打开右侧房间，C 打开上方横道，B 打开 D 的装载门和一扇出口门，D 打开下方回程和最后一扇出口门。
- 沿用 01 的四拍周期，前两拍伸出、后两拍收起，不增加控制规则。本关将节拍用于保护暂存资源：搬运第二箱时，第一箱所在的位置仍会受到周期门影响，不能只考虑眼前的送箱窗口。
- 第一层矛盾：上方箱子先压 A 才能取出远处箱子，但它离开 A 后右侧房间就会关闭。需要先把第二箱取出、运到左房间的 C，打开上路，才有站位继续搬走第一箱。上方横道贴墙，普通推箱无法将第一箱向下送进房间，仍须利用周期门转向。
- 第二层矛盾：第一箱若留在周期门格，搬运第二箱时，关门会让它落到 B，堵住第二箱还要经过的中央桥；但 B 未压住时，第二箱又不能进入 D。需要先保护第一箱，将第二箱送过中央桥、暂放在 D 门前，再允许第一箱落上 B，放行最后一段运输。
- 核心发现：趁周期门收起，把第一箱推过门格，停进右侧上方的安全位置。只停在刚过 C 门的位置也不够，第二箱离开 C 后，关闭的门会占住继续推第一箱所需的站位。暂存既要避开周期推力，也要保留后续取回的方向。
- 上方有两处暂存位置，各自改变第二箱的转弯安排。靠近周期门的位置占住右房间左列上方的站位，第二箱需要走到更右边再向下转；更远的位置让出这个站位，却挡住通往右端上方的路线，需要在中央桥右端转入房间。第二箱就绪后，再从右侧将第一箱推回周期门格，送到 B。
- 补救设计：第一箱过早落上 B 后，可以先保留第二箱压 C，将第一箱向右暂推、绕到右侧，再向左收回房间暂存，重新腾出中央桥。最后回填 B 时，要先将箱子推过 B，再从右侧推回，让角色留在右房间，继续完成 D 和回程。错误的先后顺序可以通过清路与重新安排站位修正。

## 03 接驳：交替过桥，再决定谁回运

- 地图 20 × 10，两箱、三块压板、五扇压力门、两扇周期门和一个周期轴。左房间连接上方捷径与中央运输桥，右房间连接储箱室和下方终点。A 打开上方捷径、D 的装载门与一扇出口门；B 打开储箱室；D 打开最后一扇出口门。
- 沿用四拍周期，结合第一章已经学过的相反初始状态：桥的左门前两拍伸出、后两拍收起，右门恰好相反，伸出方向也分别朝右、朝左。两门同色、方向相对，中间留出两格接应位置。没有入口演示，玩家在运输桥上面对“两扇门从不同时收起，却必须送箱过去”的矛盾，利用已知的关门推力验证接驳方式。
- 核心发现：去程趁左门收起装入箱子，利用它伸出时的推力，将角色与箱子一起送到桥中段，再利用右门的窗口卸下。回运则由右门先把箱子推入桥中，角色随后跟进。货物到达对岸后，远侧门伸出可能将角色退回桥内；中间两格允许来回调整拍位，等门收起再跟上。同一座桥承担双向运输，两次入桥需要各自安排时机。
- 第一层矛盾：A 离开局箱子更近，先压住它就能打开上方捷径并提前准备终点；但另一箱仍被 B 门关在储箱室，唯一可用的箱子必须先过桥压 B。上方捷径可以帮助观察右房间，却不能代替运输桥取得第二箱。A 的长期占用要等箱子资源够用后再安排。
- 第二层矛盾：B 既是放出第二箱的开关，又在回运的装载路线上。离开 B 前，必须把储箱室的箱子卸得足够远，越过门关闭后会占用的推箱站位；只推出门口就撤走控制箱，会失去继续向左推它的位置。两箱都进入右房间后，还要让出回运箱的转弯与入桥站位。
- 候选分工：可以让去程箱绕到右下方暂存，将取出的箱子装上桥、送回 A；也可以先将取出的箱子从上方横移到右下方，让原来压 B 的箱子原路回运。前者让两箱各过桥一次，需要清出第二箱向下装载的位置；后者让去程箱往返，第二箱留在右侧准备终点，暂存过程中仍由去程箱维持 B。
- 第三层矛盾：右下方的箱子尚不能直接完成 D，A 控制的装载门仍关闭；而回运到 A 的箱子一旦就位，又不适合再取回担当其他开关。需要先在门前候接、保留上方最后向下推动的站位，再完成左侧 A。此时上方捷径改为角色的回程路，角色返回右房间，完成 D 后从侧边绕入出口。
- 补救安排：B 上的箱子可以向下取回，储箱室前和右下方留有重新分工的空间。若先把去程箱留右，仍可在装桥前交换两箱用途；若回运拍位不合适，可以退回岸边或在桥中段调整。需要在最终占住 A、D 之前完成资源回收与路线选择。

## 04 放行：角色接替许可，再安排运输换班

- 地图 18 × 11，两箱、三块压板、五扇门和一个周期轴。左右房间通过上方装载口和下方回程相连，右房间下方是 C 的终点小室。A 与四拍周期轴共同控制装载门；B 打开下方回程与一扇出口门，同时反向封住终点小室；C 打开最后一扇出口门。
- 已学前提是多输入须同时成立、压力可由角色接替、门可推动整排物体，以及有效行动推进周期。本关把压力与周期作为同一扇门的两个输入：只有 A 被压住、周期又处于后两拍，装载门才收起。A、周期轴和装载门同色，玩家直接在主运输口比较压板占用、拍位与门的响应，不另设入口演示。
- 第一层矛盾：想把一箱固定留在 A，为另一箱维持开门许可，但 A 本身就在上路的装载线上，会堵住货箱。需要让货箱先压住 A，角色随后接替；角色越过 A、进入门格时，压力条件撤回，即使仍在周期的放行拍位，门也会伸出，把角色与前方箱子一起送入右房间。周期继续前进，控制的是动作许可。
- 第二层矛盾：第一箱到 B 后打开回程，角色才能回左房间搬第二箱；但维持 B 又会封住 C 的唯一入口。要先把第二箱带入右房间，再撤掉 B 的占位，允许一箱进入终点小室，最后重新补上 B 才能离场。只把第二箱沿下路送进来，仍不能在第一箱一直压 B 的情况下直接完成 C。
- 上路接力：保留第一箱压 B，将第二箱送回装载口。门伸出时，整排推力会把第一箱向右送出 B，第二箱同时接替 B。此时 C 仍关闭，不能一路送到底。先把第一箱停在小室门前，再将接替 B 的箱子向右暂存，并让出第一箱继续向下推动所需的站位，才能撤回终点入口的封锁。
- 下路绕运：保留第一箱压 B，将第二箱沿下方通路带进右房间。靠近入口暂存会占住第一箱直接向下转弯的位置，需要让第一箱先向右换列；送得更远可以让出这条路线，但第二箱之后要从右侧收回，再利用下方侧位转向 B。两种暂存都要先让出通往终点小室的运输线，再撤掉 B。
- 关键取舍：上路需要准备拍位并利用整排推进接力，却仍须把新接班的箱子从 B 撤走；下路避开第二次周期装载，但把顺序问题转化为暂存与转弯站位。第一次压 B 是为了搬回第二箱，中途松开 B 是为了送货，最后补回 B 才是为了出口，同一资源不能从首次就位起一直固定不动。
- 补救安排：C 旁边与下方保留绕行和向上推箱的位置。若第二箱仍在左房间就过早完成 C，可以从下方将终点箱推回右房间、再补上 B，恢复回程。完成 C 后也要先让角色退回右房间，再重新占住 B，避免将自己留在关闭的终点入口后方。

## 05 共台：选择进料路线，再交还共用转运口

- 地图 17 × 12，两箱、两块压板、八扇门和两根周期轴。左上是首箱与装载房间，左下储箱室由 C 开门；中央上路和下方进料口通向同一个转运台，右端留有暂存位，右下房间负责接收与回收，出口位于左下。C 同时打开储箱室、上方暂存位的侧面通道和一扇出口门；D 打开底部回程和另一扇出口门。
- 已学前提是有效行动推进周期、相反初始状态、门推动物体，以及压板可以暂时释放后重新补上。四拍轴沿用前两拍假、后两拍真的规律，同时控制上路装载门与反向的下方进料门；六拍轴前三拍假、后三拍真，控制向下卸货的门。两轴分别着色并显示各自拍位。与 04 用压力许可配合单周期不同，本关要观察两个持续前进的周期，并把装载、接应和退出作为一次完整安排。
- 发现与教学融入主运输口：上路放行不保证卸货门也收起，下方进料口又与上路交替开放。首箱必须借卸货门向下转弯，玩家在中央准备区比较两根轴的刻度和门的响应，确认四拍轴转过一圈后，六拍轴尚未回到原位。门前横道和下方侧位提供调整行动的空间，不需要先计算共同周期，也不能单独调整某根轴。
- 第一层矛盾：D 能尽早打开底部回程，看起来适合先完成，但第二箱仍在 C 控制的储箱室内。首箱必须先承担 C 的临时许可。C 又位于卸货竖道中，若把首箱从此固定下来，第二箱即使进入转运台，也不能沿竖道送入接收房间。必须先取出第二箱，再让首箱离开 C，最后重新补回 C。
- 上路暂存方案：维持首箱压 C，将第二箱送回左上房间，经装载门推到卸货门右侧的暂存位。它不再受卸货门的周期推力影响，也让出下方进料与换边位置；但回收时必须从 C 打开的侧面通道绕到箱子右边，将箱子向左推回卸货门。需要先完成这次取回，再把首箱从 C 移往 D，否则暂存箱会失去背后的站位。第二箱落在竖道上端时，角色可沿仍开放的侧面通道进入接收房间，清走 C 上的首箱。
- 下方候接方案：将第二箱沿下路带到中央，利用反向进料门的窗口向上送入侧位，暂不送进卸货区。此时可以提前将首箱从 C 移到 D，打开底部回程，再回来完成第二箱的装载。代价是第二箱占住下方换边路线，角色要借上路绕行；以后若再把它推到卸货门右侧，也已没有 C 许可可供取回。向上送到转运台后，右侧小站位允许角色继续行动，等待下门收起，再从左房间绕到箱子左侧横向装载。
- 一对多的取舍贯穿两条路线：上路装载门收起时，下方进料门伸出；为六拍卸货门调整拍位，也会改变四拍轴控制的两处通路。下方进料时，关门可以把角色退回下侧，而箱子已越过门格。需要区分货物已经到达、角色能够跟进，以及还能否返回左侧重新站位，不能只选择一扇门开放的时刻。
- 关键回收与补救：首箱移到 D 后，角色可经底部回程绕回转运台，从卸货门上方将第二箱送到 C；最后从接收房间侧面绕过 C，经底部返回出口。两块压板周围保留重新推动的空间；若提前撤掉 C 导致上方暂存箱无法取回，可将 D 的箱子重新送回 C，恢复侧面通道，再调整取回顺序。最终占住 C、D 之前，临时许可与运输路线仍可重新安排。
