# 第二章：步数与节拍

第二章引入周期轴与周期门，把有效行动的拍数和空间中的运输、站位与回程结合起来。目前有 01「合拍」和 02「候场」，沿用第一章已经教过的箱子、压力板和门推挤，不引入传送带、停轴、多周期或多输入条件。

## 01 合拍：先装载，再回收，最后交接

- 地图 15 × 11，两箱、三压板、四扇压力门、两扇周期门和一个周期轴。左房间安排箱子分工与装载，右侧竖道负责运输，下方通道承担回程，右房间提供暂存和交接空间。周期轴放在右上角不可到达的孤岛上，与两扇周期门同色。下文用 A、B、C 分别指紫色装载压板、青色回程压板和玫红色终点压板。
- 入口先安全展示四拍周期：前两拍关闭、后两拍收起，有效行动才推进一拍。入口门下方留有安全落点，即使恰逢关门，也只会把角色推入房间。随后在主区域把同样的开闭规律用于箱子转运。
- 第一层矛盾：A 既是打开装载通道的开关，又是向右推送货箱必需的站位。若先让一箱长期压住 A，另一箱就无法进入上方通道。需要先把货箱送到门前暂存，再安排控制箱压住 A；也可以在发现占位冲突后移开箱子、重新分工。左房间保留绕行位置，两只箱子都可以承担货物或控制任务。
- 装载点上方和右侧都是墙，角色没有向下推箱的站位。趁周期门收起时把货箱送进门格，再利用门伸出将它推入竖道；之后还要等门收起，进入它让出的站位，把货箱继续送往 B。节拍决定装载与卸载的窗口，门的推力负责完成普通推箱无法完成的转弯。
- 第二层矛盾：货箱暂压 B 打开下方回程，但从 B 推回终点 C 时，回程门会关闭，C 上的箱子又会堵住上方竖道。必须提前回收 A 的控制箱，从下路带进右房间，再让它接替 B。B 还控制出口前的一扇门，货箱首次经过 C 时不能直接离场。
- 第三层矛盾：带来的控制箱可能占住 B 下方的推箱站位，也可能被过早推入无法回收的角落。右房间的侧边和上方侧位都能暂存，需先让出站位，再在货箱离开 B 后回填。若控制箱仍留在 A 就提前完成 C，角色会被困在右侧，需要撤销。
- 两套参考方案分别为 87 和 91 步，采用相反的箱子职责与不同暂存位置，都利用周期门推动货箱，未破坏实体。它们是可行方案，不作为唯一解或最短解要求。

## 02 候场：先保护已经送到门口的箱子，再允许它落下

- **重做依据**：原版「接拍」被试玩否决。虽然能够交换两箱身份，但唯一装载口之后的操作顺序仍然显而易见，没有满足候选方案应有实质差别的要求。新版围绕反馈中的问题重新布局：搬运第二箱会继续推进周期，第一箱若过早落下，就占住第二箱还需要经过的运输路。扩大面积和增加步数不作为重做目标。
- **已学前提与本关新发现**：沿用 01 的四拍周期，前两拍伸出、后两拍收起，不增加周期长度或控制规则。与 01 的装载、回收、压板接力不同，这次要决定暂时不完成一个看似正确的目标，并为不同暂存方案保留各自的推箱站位。
- **地图与机关**：地图 17 × 10，仍为两箱，四块压板、六扇压力门、一扇周期门和一个周期轴。上方横道承载第一箱，中央桥是第二箱的运输路，下方是受 D 控制的回程，左右房间分别提供暂存和终点准备空间。A 打开右侧第二箱所在的房间；C 打开第一箱前方的上路；周期门向下把箱子送上中央桥的 B；B 同时打开出口前门和 D 的装载门；D 再打开下路回程与最后一扇出口门。
- **第一层矛盾：控制资源还要成为货物**。上方箱子先压 A 才能取出远处箱子，但它离开 A 后远处房间就会关闭。第二箱需先取出、运往左房间的 C，打开上路，才有站位继续搬走第一箱。上方横道的上侧全部封墙，普通推箱不能把第一箱直接向下送进房间，仍须利用周期门转向。
- **第二层矛盾：过早完成 B 会封住第二箱的运输路**。第二箱接下来要从 C 运回右房间。第一箱若停在周期门格，角色去推第二箱的途中，关门会让第一箱落到 B，堵住中央桥。下路此时也没有打开。反过来，B 未压住时 D 的入口门又不通，第二箱不能先把 D 完成。需要先将第二箱送过中央桥、暂放在 D 门前，再允许第一箱最终占住 B。
- **候选方案一：越过门口，停进上方内侧暂存格**。趁收门的窗口，将第一箱连续推过门格，停在右侧 `(9,3)`，周期门随后的伸出只把角色送到桥上。搬第二箱时，第一箱留在门外的安全位置。这个暂存格占了右房间左列上方的站位，因此第二箱需要走到更右边，再从上方转向 D 的门前。准备完成后，从右侧将第一箱推回门格，才让它落上 B。
- **候选方案二：再多让出一个上方站位**。第一箱也可以停在 `(10,3)`。它让出了 `(9,3)`，却切断了通向右端上方站位的路线，不能照搬前一种方案把第二箱推到最右列再向下转弯。可改在中央桥右端向下转入右房间，再横送到 D 门前。两条路线的差别在第二箱的转弯方向和角色的换边路线，而非交换箱子编号。
- **候选方案三：提前落下以后，主动清路补救**。不强制撤销过早触发。保留第二箱压住 C，先把 B 上的箱子向右暂推、从下侧绕到它右边，再将它向左收回，利用仍然打开的 C 门站位将箱子送进左侧 `(6,5)` 暂存。中央桥腾空后，第二箱可以运往右侧。最后回填 B 时，还要先把箱子推过 B，再从右侧推回来，保证角色最终也在右侧；直接从左边填 B 会把自己留在尚未打开的下路之外。
- **需要排除或修正的计划**：刚过 C 门就把第一箱停在 `(7,3)` 看似已离开机关，但第二箱离开 C 后，门格 `(6,3)` 被占住，继续向右推第一箱的站位随之消失，需要重新压 C 才能取回；第一箱提前落到 B 后保持它不动，第二箱就无法到达 D 的门前；直接把第一箱从 B 送往 D，则会先释放 B、关闭 D 的入口门，也需要重新安排箱子用途和暂存。不能只看目标是否亮起，要检查当前运输和下一次推动所需的位置。
- **验证范围**：保留三条正式引擎参考回放，分别为 89 / 101 / 114 步，对应两种上方保护方案与左侧补救方案，均不破坏实体。关卡测试还覆盖周期门最终送箱时的动画中撤销与重置、第二箱在 D 门前受阻不推进周期，以及近侧暂存丢失站位的分支。另对第一箱已提前压 B、第二箱仍在 C 的具体局面做限制搜索，保持第一箱压 B、不破坏实体时，穷举 1,244 个状态未能将第二箱送到 D。实际浏览器已逐步核对三条路线的角色、箱子位置与拍位并完成通关，另复查最终送箱回合的撤销和重来。没有穷举整关所有解法；参考步数和搜索结果不代表趣味性已经得到证明。
- **试玩重点**：玩家能否提出并检验“先完成 B”“先完成 D”“停在 C 门之后”“越过周期门再暂存”等不同计划；能否在机关提前触发后看出仍可清路补救；两个上方暂存位置是否真的导致不同的转弯安排；若只需沿着一串机关顺推，仍应重做。01 的地图与解法保持不变。
