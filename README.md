# Modoban

Modoban 是一款以数论思想为基础的回合制网格推箱解谜游戏。名称结合了 modulo（取模）与 Sokoban（推箱子）。玩家通过搬运箱子、调整周期机关和利用传送带，安排一连串机关反应，最终到达出口。

`src/engine` 已实现独立于界面的逻辑引擎、动作记录、动画时间线和输入控制器
